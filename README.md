# prototype-Design — DesignNest Auth Prototype

Prototype halaman autentikasi untuk **DesignNest** (marketplace desain fashion digital), dibuat dalam HTML/CSS statis — desktop & mobile.

## Halaman

| # | Halaman | File |
|---|---------|------|
| 1 | Login (utama) | `login.html` |
| 2 | Register — Buyer | `register-buyer.html` |
| 3 | Register — Seller/Desainer | `register-seller.html` |
| 4 | Forgot Password | `forgot-password.html` |
| 5 | Mobile — Login | `mobile-login.html` |
| 6 | Mobile — Register Buyer | `mobile-register-buyer.html` |
| 7 | Mobile — Register Seller | `mobile-register-seller.html` |
| 8 | Mobile — Forgot Password | `mobile-forgot-password.html` |

Buka `index.html` untuk melihat daftar/navigasi seluruh halaman.

## Lihat secara online

Jika GitHub Pages diaktifkan untuk repo ini (Settings → Pages → Deploy from branch `main` / root), halaman dapat diakses di:

```
https://shbrn89.github.io/prototype-Design/
```

## Import ke Figma

Gunakan plugin Figma **html.to.design**:
1. Install plugin dari Figma Community.
2. Pilih tab **Import via URL**.
3. Paste URL tiap halaman (contoh: `https://shbrn89.github.io/prototype-Design/login.html`).
4. Plugin akan mengubahnya menjadi frame Figma asli yang bisa diedit (layer, teks, warna).
5. Ulangi untuk setiap halaman, lalu susun dalam satu file Figma.

## Catatan desain

Panel gambar/moodboard pada tiap halaman dibuat sebagai ilustrasi CSS (bentuk, sketsa garis, polaroid) bertema krem-olive — bukan foto asli. Setelah diimpor ke Figma, elemen ini dapat diganti dengan foto produk/moodboard asli.
