# prototype-Design — TokoGaris Auth Prototype

Prototype halaman autentikasi untuk **TokoGaris** (marketplace desain fashion digital), dibuat dalam HTML/CSS statis — desktop & mobile.

## Halaman

| # | Halaman | File |
|---|---------|------|
| 1 | Login (utama) | `login.html` |
| 2 | Register — Buyer | `register-buyer.html` |
| 3 | Register — Seller/Desainer | `register-seller.html` |
| 4 | Forgot Password | `forgot-password.html` |
| 5 | Mobile — Login | `mobile-login.html` |
| 6 | Mobile — Register Buyer | `mobile-register-buyer.html` |
| 7 | Mobile — Register Seller | `mobile-register-seller.html` |
| 8 | Mobile — Forgot Password | `mobile-forgot-password.html` |

Buka `index.html` untuk melihat daftar/navigasi seluruh halaman.
